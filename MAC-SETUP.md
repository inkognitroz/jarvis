# Mac setup — MMIR mode

The default backend is now MMIR, not Claude Code. Follow [MMIR-SETUP.md](MMIR-SETUP.md).

```bash
bash scripts/install-mmir-mac.sh
npm start -- --open
```

Do not use the older Claude install script for MMIR. No Claude login or inherited MCP
configuration is needed. The older setup description is preserved in
[MAC-SETUP-CLAUDE.md](MAC-SETUP-CLAUDE.md) for explicit legacy use only.
